# ZZRastan 1.0

First public release of **ZZRastan**, a standalone Rastan arcade-hardware
recreation for Amiga systems equipped with an MNT ZZ9000.

The arcade emulation runs on the ZZ9000 ARM Core1; AmigaOS provides RTG display,
input, AHI audio and host integration.

## Highlights

- Smooth ~60 Hz gameplay
- World and Japan ROM sets supported
- YM2151 + MSM5205 audio
- Faithful mono output
- Keyboard controls
- Two-button DB9 joystick support
- USB game-controller support
- Pause
- Infinite-lives trainer
- Clean Core1 stop/relaunch
- Hardware-tested on 68060/50 and 68030/25 systems

## Requirements

- MNT ZZ9000
- matching XACP-compatible firmware / `zz9000.card`
- Picasso96 / RTG
- AHI
- your own legal Rastan arcade ROM dump

**No game ROMs are included.**
