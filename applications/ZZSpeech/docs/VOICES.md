# Voices

The default voice included in the Aminet release is:

```text
slt.flitevox
```

Other free Flite voices can be downloaded from:

http://festvox.org/flite/packed/flite-2.1/voices/

ZZSpeech currently supports only `.flitevox` voices smaller than 16 MB, due to the fixed voice loading area used by the Core1 blob.

The default Flite voice is intelligible but synthetic. This is not neural TTS.
