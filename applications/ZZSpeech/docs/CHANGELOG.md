# Changelog

## 1.0

Initial Aminet release.

- Resident ZZSpeech daemon.
- Core1 ARM Flite blob loaded at runtime.
- Intuition/GadTools GUI.
- CLI client `ZZSay`.
- Write-only DOS handler `ZZSPEECH:`.
- AHI playback.
- External `.flitevox` voice support.
- Default `slt.flitevox` voice included in the Aminet release.
